# 生成式AI 學習筆記站

長庚大學人工智慧學系「生成式AI」課程的個人學習筆記網站。純靜態 HTML + CSS，部署在 GitHub Pages。

- 網站：https://icecouldbe.github.io/Website_1/
- AI 協作規則：[CLAUDE.md](CLAUDE.md)（新增頁面前，請先讀這份）

- 02 [提示詞基本功](notes/02-prompt-basics.html)
- 03 [Vibe Coding 與規則驅動開發](notes/03-vibe-coding-vs-rules.html)
- 04 [怎麼寫好 CLAUDE.md](notes/04-writing-claude-md.html)

## 如何新增筆記

對 AI 說：

```
請依照 CLAUDE.md，新增一篇關於「主題名稱」的筆記。
```

AI 會複製 `templates/note-template.html`、依固定章節撰寫內容，並同步更新首頁與本檔案。

## 本機預覽

不需要安裝任何東西，直接用瀏覽器開啟 `index.html` 即可。
